## How to Compile

From a terminal (Command Prompt, PowerShell, or a Linux/Mac terminal) in the same folder as `console_ui.cpp`, run:

```
g++ -std=c++17 -pthread console_ui.cpp CommandInterpreter.cpp MarqueeEngine.cpp Terminal.cpp -o mc03
```

## How to Run

```
mc03
```

On Mac/Linux: `./mc03`
